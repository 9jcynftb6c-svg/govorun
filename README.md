# Говорун

## Как выложить сайт (Vercel)

1. Создайте аккаунт на github.com (если ещё нет).
2. Создайте новый репозиторий, например `govorun`.
3. Загрузите ВСЕ файлы и папки из этого архива в репозиторий
   (на странице репозитория: "Add file" → "Upload files",
   перетащите все файлы, включая папку `src`).
4. Зайдите на vercel.com, войдите через GitHub.
5. "Add New Project" → выберите репозиторий `govorun` → "Deploy".
6. Через 1-2 минуты сайт будет доступен по ссылке вида
   `govorun.vercel.app`.

## Как вносить изменения потом

1. Получите от Claude обновлённый файл `App.jsx`.
2. На GitHub откройте `src/App.jsx` → значок карандаша (Edit) →
   замените содержимое на новое → "Commit changes".
3. Vercel сам пересоберёт и обновит сайт автоматически.
